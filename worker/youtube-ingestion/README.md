# YouTube Ingestion Worker — статус: припаркован

**Этот сервис сейчас не используется в проде и не деплоится.** Основной путь
извлечения субтитров для `/library/new` — браузерное расширение
(`browser-extension/`, Gate #2C), а не этот воркер.

## Почему припаркован

Gate #2B (`docs/ui/m3-slice12-production-architecture.md`) проверил деплой на
Render Free и получил два независимых блокера:

- YouTube банит/рейт-лимитит shared-egress IP Render Free — 3/3 реальных
  попытки упали одинаково на этапе получения метаданных видео.
- `faster-whisper` упирается в лимит памяти Render Free (512MB) — воспроизведено
  1958 раз подряд на самом маленьком тестовом клипе.

Ни то, ни другое не чинится в коде этого воркера — это ограничения
бесплатного хостинга. Полный разбор: `docs/ui/m3-slice12-gate2c-browser-bridge-primary.md`.

## Что с ним делать дальше

Код рабочий и протестированный (`npm test` — 41 юнит-тест, все проходят при
запуске `node --test test/*.test.mjs`; сам npm-скрипт `test` в этом пакете
сейчас ломается на Node 22 при вызове `node --test test/` без явного
глоба — известная мелкая проблема обвязки, не логики). Он держится в
репозитории как задел на будущее: если проект переедет на платный тир
(Render/Fly/VPS с выделенным IP и памятью ≥1-2GB), этот воркер — готовая
отправная точка для реализации серверного provider-chain из
`docs/ui/m3-slice12-production-architecture.md`.

Пока это не сделано, ничего в этой директории не деплоится и не вызывается
из основного Next.js-приложения.
