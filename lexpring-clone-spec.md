## 1. Идея продукта в одном абзаце

Приложение учит язык через чтение реальных текстов, а не через отдельные слова или геймификацию. Пользователь читает текст (свой — вставленный/импортированный, или из библиотеки), тапает на непонятное слово или фразу — получает мгновенный перевод с учётом контекста — одним касанием сохраняет слово в свою колоду — периодически повторяет слова через флэшкарты с интервальным повторением (spaced repetition). Ключевая метафора: не "учить язык", а "читать и попутно накапливать словарь из того, что реально читаешь".

## 2. Кому это нужно (JTBD)

- Люди уровня A2–C1, которым скучно в Duolingo/аналогах (нет реального контента, только упражнения).
- Люди, которые уже читают на языке (статьи, посты, субтитры, лирику) и хотят не терять слова, которые встречают.
- Изучающие язык "через контент, который им реально интересен" (новости, любимый автор, транскрипты YouTube-видео), а не через учебник.

## 3. Ключевой пользовательский флоу (must work end-to-end в MVP)

1. Онбординг → выбор изучаемого языка и родного языка → (опционально) уровень и цель (сколько слов в день) → создание аккаунта.
2. Экран «Библиотека»: список текстов — свои импортированные + несколько стартовых текстов от приложения.
3. Добавление текста: вставить текст руками / вставить ссылку на статью / вставить ссылку на YouTube (парсинг субтитров) → текст появляется в библиотеке.
4. Экран «Читалка»: текст отображается, тап по слову → всплывающая карточка с переводом (слово/фраза + перевод в контексте предложения) → кнопка "Сохранить в словарь".
5. Экран «Мой словарь» (notebook): все сохранённые слова, сгруппированы по тексту-источнику и/или по колодам, с фильтрами (новые / изучаются / выучены).
6. Экран «Повторение» (flashcards session): SRS-очередь слов на сегодня, свайпы "помню/не помню", прогресс сессии.
7. Экран «Прогресс»: стрик, слов сохранено, слов выучено, минут чтения, график по дням.
8. Пэйвол на премиум-фичи (см. раздел 9) с оплатой через сторы.

## 4. Полная карта экранов

### 4.1 Онбординг (5–8 шагов, свайп/next-конец в конец)
- Welcome / value prop (1 экран, без выбора).
- Какой язык учишь? (список языков, поиск).
- Какой у тебя родной язык? (для перевода).
- Твой текущий уровень (A1–C2 или "начинающий/средний/продвинутый" — проще).
- Зачем тебе язык? (путешествия / работа / фильмы-без-субтитров / переезд / просто интерес) — используется потом для рекомендаций текстов.
- Сколько слов в день хочешь учить? (слайдер 5/10/20/30 — это создаёт daily goal).
- Создание аккаунта (email+пароль или Apple/Google Sign-In — **обязательно **Sign in with Apple**, если публикуешь в App Store и есть другие соц-логины — требование Apple).
- Экран "вот твой план" (сколько слов за месяц при таком темпе) → paywall (см. 9.3) → в библиотеку.

### 4.2 Библиотека (Home)
- Табы: "Мои тексты" / "Библиотека приложения" (готовый контент по уровням и темам) / возможно "Импортировано".
- Карточка текста: заголовок, язык, оценочное время чтения, % новых слов в тексте относительно уже изученных (фича "сложность текста под тебя" — сильный дифференциатор).
- FAB "+" → модалка добавления: (a) вставить текст, (b) вставить URL статьи, (c) вставить URL видео (YouTube) — тянем субтитры, (d) сфотографировать текст (OCR) — можно вынести в V2.

### 4.3 Читалка (Reader) — ядро продукта
- Чистый typographic layout, настройки шрифта/размера/светлая-тёмная тема.
- Тап по слову → инлайн-попап (не полноэкранный, не перекрывает контекст) с: словом, транскрипцией (если применимо), переводом слова вне контекста и переводом в контексте предложения, кнопкой "🔊 озвучить" (TTS), кнопкой "+ в словарь".
- Long-press / выделение → перевод фразы/предложения целиком, не только слова.
- Уже сохранённые слова подсвечены в тексте (например, подчёркнуты) — визуальный фидбек "я это уже учу".
- Кнопка "Закончить/отметить прочитанным" внизу — засчитывает время чтения в статистику.

### 4.4 Мой словарь / Notebook
- Список слов: слово — перевод — статус (новое/изучается/выучено) — источник (из какого текста).
- Свайп-действия: удалить, отметить как "уже знаю" (не показывать в флэшкартах).
- Поиск и фильтр по тексту-источнику, по языку, по статусу.
- Возможность добавить фото к карточке слова (эта фича явно упомянута в истории версий референса — "1.1.0: возможность добавить фотографии в карточки") — визуальная мнемоника.
- Ручное добавление слова без текста-источника (для слов, услышанных где-то ещё).

### 4.5 Повторение / Flashcards session
- Режим "сессия на сегодня": колода слов, у которых наступил срок повторения по SRS.
- Формат карточки: перевод → пользователь вспоминает слово → тап "показать ответ" → 4 кнопки оценки (см. алгоритм SM-2 в разделе 7): "не помню" / "трудно" / "помню" / "легко".
- Альтернативный режим для разнообразия (V2): "выбери из 4 вариантов", "напиши слово", "сопоставь пары".
- В конце сессии — экран с итогами (сколько слов повторено, текущий стрик).

### 4.6 Прогресс / Статистика
- Стрик дней подряд.
- Всего слов в словаре / выучено (доля выученных = % слов с длинным интервалом повторения).
- Минут чтения всего/за неделю.
- График активности по дням (heatmap как в GitHub).

### 4.7 Настройки
- Профиль, языки (изучаемый/родной), цель в день.
- Уведомления (напоминание о повторении, напоминание о стрике).
- Управление подпиской.
- Экспорт словаря (CSV) — маленькая, но важная фича доверия.

### 4.8 Paywall
- Показывается: после онбординга, при попытке импортировать больше N текстов в бесплатном тарифе, при попытке сохранить больше N слов в день, при попытке зайти в текст выше бесплатного лимита длины.

## 5. Модель данных (реляционная, Postgres/Supabase-совместимая)

```sql
-- пользователи (в Supabase auth.users уже есть базовая сущность, здесь — профиль)
profiles (
  id uuid primary key references auth.users(id),
  target_language text not null,      -- 'en', 'es', ...
  native_language text not null,
  level text,                          -- 'a1'..'c2'
  daily_word_goal int default 10,
  streak_current int default 0,
  streak_longest int default 0,
  last_active_date date,
  created_at timestamptz default now()
)

texts (
  id uuid primary key default gen_random_uuid(),
  owner_id uuid references profiles(id),   -- null = системный/библиотечный текст
  title text not null,
  body text not null,                       -- очищенный текст
  source_type text check (source_type in ('manual','article_url','youtube','system')),
  source_url text,
  language text not null,
  level_tag text,                           -- для библиотечных: 'a2','b1' и т.д.
  word_count int,
  created_at timestamptz default now()
)

vocabulary_items (
  id uuid primary key default gen_random_uuid(),
  owner_id uuid references profiles(id) not null,
  source_text_id uuid references texts(id),
  headword text not null,               -- слово/фраза в исходной форме
  translation text not null,
  context_sentence text,                -- предложение, из которого взяли слово
  context_translation text,
  photo_url text,
  status text default 'new' check (status in ('new','learning','known','ignored')),
  created_at timestamptz default now()
)

srs_state (
  vocabulary_item_id uuid primary key references vocabulary_items(id),
  ease_factor numeric default 2.5,      -- SM-2
  interval_days numeric default 0,
  repetitions int default 0,
  due_at timestamptz default now(),
  last_reviewed_at timestamptz
)

review_log (
  id uuid primary key default gen_random_uuid(),
  vocabulary_item_id uuid references vocabulary_items(id),
  reviewed_at timestamptz default now(),
  grade int  -- 0..3, соответствует "не помню/трудно/помню/легко"
)

reading_sessions (
  id uuid primary key default gen_random_uuid(),
  owner_id uuid references profiles(id),
  text_id uuid references texts(id),
  started_at timestamptz,
  ended_at timestamptz,
  words_looked_up int default 0
)

subscriptions (
  owner_id uuid primary key references profiles(id),
  plan text check (plan in ('free','premium_monthly','premium_yearly')),
  status text,                       -- 'active','expired','trial','canceled'
  provider text,                     -- 'apple','google','stripe'
  current_period_end timestamptz
)
```

Индексы: `vocabulary_items(owner_id, status)`, `srs_state(due_at)` (для быстрой выборки очереди повторений), `texts(owner_id, language)`.

## 6. Алгоритм интервального повторения (SM-2, конкретная реализация)

Используй классический SM-2 (как в Anki) — проверенный, простой, не нужно ничего изобретать.

Вход: оценка `grade` от 0 до 3 (маппинг кнопок: "не помню"=0, "трудно"=1, "помню"=2, "легко"=3 — упрощённая 4-балльная версия вместо классической 0-5, этого достаточно для мобильного UX).

```
if grade == 0:
    repetitions = 0
    interval_days = 1
else:
    if repetitions == 0:
        interval_days = 1
    elif repetitions == 1:
        interval_days = 6
    else:
        interval_days = round(interval_days * ease_factor)
    repetitions += 1

ease_factor = ease_factor + (0.1 - (3 - grade) * (0.08 + (3 - grade) * 0.02))
ease_factor = max(ease_factor, 1.3)

due_at = now() + interval_days days
```

Слово считается "выученным" (для статистики прогресса) когда `interval_days >= 21` и `repetitions >= 3`.

Очередь на сегодня = `select * from srs_state where due_at <= now() order by due_at asc limit daily_word_goal_or_more`.

## 7. Перевод и tap-to-translate — техническая реализация

Три уровня, можно внедрять поэтапно:

1. **MVP**: DeepL API (лучшее качество перевода среди доступных по API, поддерживает 30+ языков) — перевод слова + перевод целого предложения отдельным вызовом для контекста. Кешируй переводы в БД (`translations_cache(source_text, source_lang, target_lang) -> translation`), чтобы не платить за повторные переводы одного и того же слова у разных пользователей.
2. **Лучше**: контекстный перевод через LLM-вызов (например, тем же MiniMax M3, который уже используешь в стеке) с промтом вида: *"Переведи слово '{word}' с {lang_from} на {lang_to} с учётом контекста предложения: '{sentence}'. Дай: 1) перевод слова в этом контексте, 2) перевод всего предложения, 3) если слово — идиома/фразовый глагол, отметь это отдельно."* Ответ парсишь как JSON (жёстко указываешь модели формат).
3. **TTS**: для озвучки слова/предложения — системный TTS устройства (бесплатно, offline, mobile-native API) в MVP; ElevenLabs/OpenAI TTS — если нужен более естественный голос в премиум-тарифе.

Импорт статьи по URL: серверная функция забирает HTML → извлекает основной текст (Readability-алгоритм, npm-пакет `@mozilla/readability` + `jsdom`) → сохраняет как `texts.source_type='article_url'`.

Импорт YouTube: получить subtitle track (есть публичные способы вытащить транскрипт по video_id без official API ключа, но это серая зона по ToS YouTube — надёжнее использовать официальный YouTube Data API v3 + captions endpoint, требует OAuth для скачивания субтитров чужого видео с ограничениями) → очистить от таймкодов → сохранить как обычный текст. **Важно предупредить пользователя**, что доступны только видео с открытыми субтитрами.

## 8. Технологический стек (рекомендация под тебя)

Раз референс уже на Next.js + Vercel и с приватной политикой на отдельной странице — вероятно, это Next.js (App Router) + Supabase. Рекомендую тот же путь, он тебе подходит и знаком:

- **Frontend**: Next.js (App Router) + React, разворачивается на Vercel. Если нужен нативный iOS/Android клиент — Capacitor обёртка поверх той же кодовой базы (не переписывать логику дважды) либо React Native, если критична производительность жестов в читалке.
- **Backend/БД/Auth**: Supabase (Postgres + Auth + Storage для фото карточек + Row Level Security на все таблицы по `owner_id = auth.uid()`).
- **Перевод**: DeepL API (ключ в `.env`) + опционально MiniMax M3 через твой Hermes Agent как второй уровень контекстного перевода — это единственное место, где твой существующий агентный стек органично встраивается в этот проект (перевод-с-контекстом можно вынести отдельным n8n workflow/webhook, который дергает MiniMax и кеширует ответ, чтобы не тащить AI SDK прямо в клиент).
- **Платежи**: RevenueCat поверх Apple StoreKit / Google Billing — сильно упрощает работу с подписками и триалами на мобильных сторах, самому Stripe напрямую для in-app подписок на iOS всё равно нельзя (Apple требует IAP).
- **Аналитика**: PostHog (self-host можно на своей VM, раз у тебя уже есть локальная инфраструктура) — трекать: onboarding_completed, word_saved, review_session_completed, paywall_viewed, subscription_started.
- **OCR (V2, для фото текста)**: on-device (Vision framework на iOS) или Google Cloud Vision API.

## 9. Монетизация

### 9.1 Бесплатный тариф (ограничения, не урезанное качество)
- До 3 своих текстов в библиотеке одновременно.
- До 10 новых слов в словарь в день.
- Базовый перевод (без контекстного LLM-объяснения идиом).
- Без импорта по URL/YouTube (только ручной ввод текста).

### 9.2 Премиум (ориентир по цене — как у референса: месячная ~449₽, годовая ~4490₽, то есть годовая ≈ цена 10 месяцев — стандартный дисконт ~17%)
- Безлимит текстов и слов.
- Импорт по URL и YouTube.
- Контекстный AI-перевод идиом и фразовых глаголов.
- Фото на карточках слов.
- Расширенная статистика.
- (опционально) премиум-голос TTS.

### 9.3 Момент показа paywall
- Сразу после онбординга (soft paywall с возможностью "продолжить бесплатно" маленькой кнопкой внизу — конверсия выше, чем hard paywall).
- В момент упора в лимит (текст №4, слово №11 за день) — контекстный paywall с точным объяснением, что именно разблокирует подписка.

## 10. Нефункциональные требования

- **Офлайн-режим**: сохранённые слова и уже загруженные тексты должны открываться без интернета (кешировать локально — IndexedDB на вебе / SQLite на нативе); перевод новых слов и синк, естественно, требуют сети.
- **Производительность читалки**: текст в 3000+ слов не должен лагать при тапах — не перерисовывать весь DOM/дерево при открытии попапа перевода, каждое слово — отдельный лёгкий элемент с обработчиком.
- **i18n интерфейса**: сам интерфейс приложения должен поддерживать минимум русский и английский с первого дня (у тебя аудитория явно рунет + шире).
- **Приватность**: минимизировать сбор данных сверх необходимого (референс, как видно из App Store privacy card, собирает email, имя, геолокацию, диагностику — на старте достаточно email + сам контент словаря; геолокацию не собирать, если не нужна для рекомендаций контента).
- **Доступность**: минимум — поддержка системного увеличения шрифта, контрастная тёмная тема.

## 11. Метрики успеха продукта

- **Activation**: % пользователей, сохранивших хотя бы 5 слов в первую сессию.
- **Retention D1/D7/D30** — стандартные для language-learning категорий, ориентир: D1 ~40%, D7 ~15-20%, D30 ~8-10%.
- **Streak retention** — % пользователей с стриком 7+ дней (сильный предиктор платящих).
- **Conversion to paid** — от просмотра paywall.
- **Words reviewed per active user per week** — показатель реального использования SRS, а не просто накопления слов "про запас".

## 12. MVP vs V2 — что резать для первого релиза

**MVP (обязательно для первого запуска):**
онбординг, ручное добавление текста, читалка с tap-to-translate (DeepL), сохранение слов, notebook, SRS-повторение (SM-2), базовый прогресс (стрик + счётчики), один платный тариф без сложных триалов, Sign in with Apple + email.

**V2 (после первых пользователей и фидбека):**
импорт по URL/YouTube, контекстный AI-перевод идиом, фото на карточках, OCR фото текста, расширенная статистика/heatmap, несколько режимов флэшкарт, экспорт CSV, push-уведомления о повторении.

**Явно не делать в MVP:** соц-фичи (лидерборды, друзья), игровая геймификация (баллы/ачивки) — референс сознательно позиционируется НЕ как геймифицированное приложение, а как инструмент для тех, кому надоела геймификация Duolingo. Не размывай позиционирование.

## 13. Итоговый компактный промт для AI-агента (можно вставлять отдельно в новую сессию Claude Code/Cursor)

```
Построй мобильное/веб-приложение для изучения языка через чтение (аналог Lexpring).
Стек: Next.js (App Router) + Supabase (Postgres/Auth/Storage) + DeepL API для перевода.
Ядро продукта: пользователь читает текст, тапает слово → получает перевод в контексте
предложения → сохраняет слово одним тапом в личный словарь → повторяет слова по
алгоритму SM-2 в режиме флэшкарт.

Реализуй в этом порядке:
1. Схема БД по разделу 5 этого документа, с Row Level Security по owner_id = auth.uid().
2. Онбординг (раздел 4.1) → создание profiles.
3. Экран читалки с tap-to-translate (раздел 4.3, 7) — это критический путь, делай первым.
4. Notebook + сохранение слов (раздел 4.4).
5. SRS-очередь и сессия повторения по формулам из раздела 6.
6. Экран прогресса (раздел 4.6) — минимальная версия: стрик + счётчики.
7. Paywall и подписки через RevenueCat в последнюю очередь, после того как основной

Не добавляй геймификацию (очки, ачивки, лидерборды) — это осознанно не про это приложение.
Каждый шаг сдавай с подтверждением: миграция применена и видна в Supabase Studio,
компонент рендерится без ошибок в браузере, ручной клик по слову в тексте реально
показывает перевод и реально пишет строку в vocabulary_items — без этого шаг не считается
завершённым.
```
