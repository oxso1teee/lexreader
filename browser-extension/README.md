# LexReader YouTube Bridge

YouTube часто скрывает `captionTracks` от IP облачных серверов, включая Vercel.
Это расширение выполняет запрос через обычный Chrome пользователя и передаёт
готовые сегменты субтитров в авторизованный LexReader.

Стороннее расширение **YouTube To Text** нельзя вызвать из LexReader: в его
`manifest.json` поле `externally_connectable` разрешает связь только с
`https://yt-to-text.com/*`. У LexReader нет доступа к его внутренним данным.
Поэтому мост реализован отдельно и не зависит от обновлений чужого расширения.

## Установка для разработки

1. Открыть `chrome://extensions`.
2. Включить **Режим разработчика**.
3. Нажать **Загрузить распакованное расширение**.
4. Скачать `lexreader-youtube-bridge.zip` из формы импорта LexReader и
   распаковать его либо выбрать папку `browser-extension` из репозитория.
5. Выбрать распакованную папку расширения.
6. Обновить страницу `https://lexreader.vercel.app/library/new`.
7. На вкладке YouTube должна появиться зелёная строка
   `LexReader Bridge подключён`.

После публикации расширения в Chrome Web Store ручная установка папки будет не
нужна.

## Что поддерживается

- обычные ссылки, `youtu.be`, Shorts и embed;
- ручные и автоматически созданные YouTube-субтитры;
- выбор дорожки языка, который пользователь изучает;
- таймкоды для синхронизации с YouTube Player;
- работа только на разрешённых доменах LexReader.

Видео без caption track пока требуют отдельного speech-to-text провайдера.
