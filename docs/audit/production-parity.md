## Ограничения этого прохода

Правила задания разрешают открыть production **только для безопасной
проверки UI**, без создания пользователей/платежей. Полная проверка
всех 33 маршрутов вживую не выполнялась, чтобы не расходовать лишние
безопасные, но не бесплатные ресурсы (MyMemory rate-limit, PostHog
event quota) без необходимости на этапе M0. Живая проверка ключевых
экранов (`/`, `/pricing`, `/home`, `/library`, `/brain`, `/progress`,
`/settings`) уже выполнялась в предыдущих сессиях этого же проекта
(см. историю задач — "Финальная проверка и деплой", "Live-verify..."
серии) и не повторялась заново здесь, так как это не входит в узкую
задачу M0 (аудит текущего состояния, не повторная приёмка уже
выпущенного функционала).
