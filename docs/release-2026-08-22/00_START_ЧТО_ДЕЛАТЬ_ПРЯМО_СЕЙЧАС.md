## Порядок работы

Делай файлы по порядку. Каждый файл — это законченный кусок работы,
который можно отдать мне (или другой сессии Claude Code) целиком как
промпт: "выполни файл 02 целиком". Не пытайся хвататься за всё сразу —
именно так проект и обгонял сам себя последние месяцы (десятки
параллельных докой-аудитов, часть багов чинится по три раза, часть висит
месяцами).

**Первое, что нужно сделать, раньше файла 01 — синхронизировать git.**
На твоей локальной машине лежит существенный объём работы, которого нет
на GitHub (см. файл 08, раздел 1). Пока это не разрулено, любой новый
анализ рискует быть частично устаревшим в момент, когда ты его читаешь.
Открой файл 08 первым, реши, что делать с локальными изменениями, потом
уже иди по порядку 01→09.
