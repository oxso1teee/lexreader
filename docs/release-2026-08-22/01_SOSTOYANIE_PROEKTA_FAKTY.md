## 4. Расхождение GitHub vs твоя локальная машина

На локальной машине (`/home/sergey/Документы/projects/English_teacher_AI`)
есть то, чего нет на GitHub `main` вообще:

- `worker/youtube-ingestion/` — отдельный Node.js-сервис (Dockerfile,
  `fly.toml` — деплой на Fly.io) для скачивания и распознавания речи
  YouTube-видео (yt-dlp + faster-whisper), с собственными тестами.
- `research/youtube-transcript/` — папка с полусотней debug-скриптов и
  Python-окружением (`whisper-venv`) — исследовательская работа по
  извлечению субтитров.
- `render.yaml` в корне — конфиг деплоя на Render.com (альтернатива
  Vercel), которого на GitHub нет.
- Три больших документа в `docs/ui/`, датированные 20.08 (то есть
  новее последнего пуша на 7 дней): `m3-slice12-production-architecture.md`
  (42 КБ), `m3-slice12-gate3-video-reader.md`, `m3-slice12-gate2c-browser-bridge-primary.md`.

Прочитал все три. Это не мусор и не заброшенная ветка — это описание
**реально протестированной** новой фичи: видео-читалка (`/watch`) с
переработанным плеером, синхронизацией по субтитрам, тапом по слову и
выделением фразы прямо поверх видео. По документу — есть скриншоты
реального прогона через Playwright с настоящим YouTube-аккаунтом и
настоящим браузерным расширением, база данных подтверждает сохранение
слов с таймкодом. Отдельно там же зафиксировано важное архитектурное
решение: серверный воркер (Fly.io/Render) **осознанно "припаркован"**
(слова из документа) после того, как бесплатный тариф Render оказался
недостаточным (YouTube банит IP шаред-хостинга, а Whisper упирается в
лимит памяти 512 МБ) — вместо него основным способом вытаскивания
субтитров стало браузерное расширение.

**Это не баг и не забытая работа — это ценный, протестированный кусок
кода, которого просто нет в `main`.** Подробный план, что с этим делать,
в файле 08. Здесь важно зафиксировать факт: **анализ в файлах 02-07
сделан по коду на GitHub `main`, а не по локальному состоянию** — часть
находок (особенно про Watch Mode/`/watch`) может быть уже переработана
локально и не соответствовать тому, что реально будет в проде после
того, как ты решишь, что делать с этой веткой работы (файл 08).
