# Пачка C — Упражнения, грамматика, учебная программа, миссии (тег: C)
Эталоны упражнений: Lesson-choice.png, Lesson-build.png, Lesson-listen.png (каркас: lessonbar с крестиком и прогрессом, eyebrow с типом задания, вопрос h2, варианты, dock «Проверить»). Реальны: учебные пути (/learning-paths: путь → этап → навык → проверка), миссии, упражнения выбора/сборки/на слух/письма по правилам. Speaking — PLANNED (нет распознавания речи).

1. **Grammar-hub** (R) — справочник грамматики: pagehead-подобная шапка с назад → Brain-home, hero-карточка «Слабое место: Present Perfect vs Past Simple — 7 ошибок за 2 недели» с кнопкой «Разобрать · 6 мин» → Grammar-lesson; чипы уровней; список тем с иконкой, уровнем CEFR, полосой освоения и статусом (Освоено / В работе / Не начато), одна с бейджем «слабое место».
2. **Grammar-lesson** (R) — урок-объяснение Present Perfect: шаги сверху (`.steps` 2 из 4: Правило → Примеры → Сравнение → Практика), формула крупной плашкой (have/has + V3) с цветовым выделением частей, 3 примера (.read + перевод), таблица-сравнение с Past Simple (две колонки-карточки), блок «Частая ошибка» (banner warn), dock: «Потренироваться · 8 заданий» → Fill-blank.
3. **Fill-blank** (R) — упражнение «заполни пропуск»: lessonbar, eyebrow, предложение .read с пропуском-слотом, 4 варианта `.tile`/`.opt` (один выбран), подсказка-ссылка «Правило», dock «Проверить». Заполни высоту: маскот с репликой `.say` сверху.
4. **Match-pairs** (R) — «соедини пары»: две колонки плиток (англ. / рус.), состояния: 1 пара уже найдена (ok, приглушена), одна плитка выбрана (on), остальные обычные; счётчик «2 из 5», таймер-бонус необязателен; dock disabled «Проверить» не нужен — вместо него строка прогресса и link2 «Пропустить». 5 пар, плитки высокие (56px).
5. **Listening-exercise** (R) — диктант: большой круглый play, волна, скорость 0.5×/1×, «осталось 2 прослушивания», поле ответа area с начатым текстом, подсказка, dock: ghost «Не могу слушать» + «Проверить» (как в эталоне Lesson-listen, но это отдельное упражнение по видео «Life in London», покажи источник).
6. **Writing-exercise** (R) — письмо по правилам (без ИИ!): карточка задания (3–4 предложения про выходные в Past Simple), чек-лист требований с галочками по мере выполнения (≥20 слов ✓, прошедшее время, 2 слова из словаря), поле с начатым текстом и счётчиком 14/20, инфо «Проверка по шаблонам правил, без ИИ», dock «Проверить» (disabled, пока < 20 слов).
7. **Speaking-exercise** (R, PLANNED) — повтори фразу вслух: фраза крупно (.read) + перевод, кнопка прослушать образец, большая кнопка микрофона (состояние записи: волна + таймер 0:03), подсказка, dock ghost «Пропустить — сейчас не могу говорить». planned:true.
8. **Placement-question** (R) — тест уровня на онбординге: lessonbar без стрика (прогресс 9/15, синий), маскот think + `.say` «Не знаешь — жми „Не знаю“, это нормально», предложение с пропуском, 4 `.opt`, dock «Ответить» + link2 «Не знаю». Назад → Goal-pick.
9. **Skill-check** (N, реальный маршрут …/[skillKey]/check) — результат проверки навыка «Present Perfect: опыт»: кольцо 8/10, вердикт «Навык подтверждён», что получилось / где ошибся (2 пункта со ссылкой на правило), награда +20 XP, dock «Следующий навык» → Unit-overview, link2 «Пройти ещё раз».
10. **Curriculum** (R) — программа (учебный путь) «Общий английский B1»: hero с общим прогрессом 44% и «следующий шаг», вертикальный список этапов-карточек с номером, темами, грамматикой, прогрессом; состояния: пройден (галочка), текущий (выделен, кнопка «Продолжить»), закрыт (lock, приглушён, «откроется после раздела 3»). Назад → Main. Смена курса — iconbtn → Course-pick.
11. **Unit-overview** (R) — раздел 3 «Работа и карьера»: hero (3 из 9 навыков, цель раздела одной фразой), список навыков с типом (слова/грамматика/чтение/проверка), статусами (пройден / текущий с кнопкой / закрыт), в конце «Итоговая проверка раздела»; dock «Продолжить: Деловая переписка». Назад → Curriculum.
12. **Level-map** (R) — карта уровней CEFR A1→C1: вертикальная «лестница» с крупными бейджами уровней, пройденные 100%, текущий B1 раскрыт (64%, что умеешь на B1 — 3 пункта, сколько слов до B2), будущие приглушены; внизу «Пересдать тест уровня» → Placement-question. Назад → Progress.
13. **Study-plan** (R, PLANNED — персонального плана нет; реальны только миссии) — план недели: сводка (цель «B2 за 6 месяцев», 15 мин/день), 7 дней строками с типом занятия, выполненные с галочкой, сегодня выделен с кнопкой, будущие бледнее; dock «Начать сегодняшнее». planned:true. Без упоминания ИИ как работающего — «план по твоему уровню и темпу».
14. **Course-pick** (R, PLANNED — несколько направлений) — выбор направления: 4 `.opt`-карточки с иконкой, описанием, числом разделов (Общий — выбран; Деловой; Путешествия; Экзамен IELTS с `.badge.soon`), dock «Сохранить». planned:true.
15. **Mission-detail** (R) — бриф миссии (реально): hero «Миссия подобрана под тебя: Закрепить Present Perfect» (9 заданий, ~6 мин, +24 XP), блок «Почему сейчас» (на основе «Мой английский», по правилам), состав миссии (3 строки: слова, грамматика, чтение), dock «Начать миссию» → Lesson-choice, link2 «Заменить миссию». Назад → Brain-home.
16. **Mission-history** (R) — история миссий: сводка (за неделю 5 миссий, 104 XP, серия), список по дням с результатом (точность, XP), статусы completed/dismissed/expired разными бейджами, сверху активная миссия дня карточкой. Назад → Mission-detail.
