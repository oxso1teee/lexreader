# Пачка G1 — Вход, онбординг, аккаунт и настройки (тег: G1)
Эталоны: Splash.png, Goal-pick.png, Placement-result.png, Profile.png, Notify-ask.png (shots/v9a/light). Формы: показывай живые состояния (фокус, заполнено, ошибка).
РЕАЛЬНО: email+пароль и magic-link, сброс пароля, настройки уведомлений (push), экспорт данных, удаление, расширение (токены). PLANNED: выбор интересов и мотивации в онбординге (нет полей профиля), соц-логин (нет).

1. **Login** (R) — вход: маскот wink + «С возвращением», поля Email (заполнено) и Пароль (фокус, иконка глаза), ссылка «Забыли пароль?» (≥44px зона) → Reset-password, «Войти», разделитель «или», ghost «Войти по ссылке из письма» → Magic-link-sent, внизу «Нет аккаунта? Создать» → Signup. Покажи inline-ошибку под паролем («Неверный email или пароль») — состояние `.field.err` + `.hint.err`.
2. **Signup** (R) — регистрация: заголовок-выгода, поля Имя / Email / Пароль с индикатором надёжности (3 сегмента), «Создать аккаунт», согласие с условиями (ссылок на внешние страницы нет — оформи как текст с подчёркнутыми span), «Уже есть аккаунт? Войти» → Login. Назад → Splash.
3. **Magic-link-sent** (N) — «Проверь почту»: иллюстрация письма (иконка ic-mail в большой плашке + маскот), адрес s•••@gmail.com, «Ссылка действует 15 минут», кнопка «Открыть почту» (ghost), таймер «Отправить ещё раз через 0:42» (disabled-ссылка), link2 «Ввести другой email» → Login.
4. **Reset-password** (R) — восстановление: иконка-плашка ic-key, объяснение, поле Email, «Отправить ссылку» → Magic-link-sent, link2 «Вспомнил пароль» → Login.
5. **Reset-password-confirm** (R) — новый пароль: баннер ok «Ссылка подтверждена», два поля (первое заполнено, с требованиями-чеклистом: 8+ символов ✓, цифра ✓, совпадают —), «Сохранить и войти» → Main.
6. **Onboarding-why** (R, PLANNED) — «Зачем тебе английский?»: lessonbar-прогресс онбординга (шаг 1 из 5), маскот + `.say`, 6 вариантов `.opt` с иконками (Работа и карьера — выбран, Путешествия, Переезд, Экзамен, Фильмы и книги, Для себя), dock «Продолжить» → Interests-pick. planned.
7. **Interests-pick** (R, PLANNED) — «Что тебе интересно?»: шаг 2 из 5, сетка 2×4 крупных плиток-тем с иконкой (выбрано 3, счётчик «выбрано 3 из минимум 3»), dock «Продолжить» → Goal-pick. planned.
8. **Account-settings** (R) — аккаунт: карточка профиля (аватар, имя, email, бейдж тарифа Free) → Profile-edit; список: Email, Пароль, Родной язык, Уровень (B1 → пересдать тест); секция «Вход»: «Выйти» ; danger-секция «Удалить аккаунт» → Delete-account. Назад → Profile.
9. **Profile-edit** (N) — редактирование профиля: аватар xl с кнопкой смены цвета/буквы (ряд из 6 цветных кружков, выбран один), поля Имя (фокус), «О себе» необязательно; переключатель «Показывать меня в рейтинге недели» (реально: рейтинг); dock «Сохранить». Шапка: закрыть + «Профиль».
10. **Notification-settings** (R) — уведомления: статус-баннер «Push включены на этом устройстве» (ok) ; секции: «Напоминания» (ежедневное в 21:00 с выбором времени-значением, «стрик под угрозой», «слова забываются»), «Соревнование» (дуэль, обогнали в рейтинге, друг напомнил про общий стрик), «Письма» (итоги недели); у каждой строки подпись и toggle; внизу «Тихие часы 23:00–8:00».
11. **Data-privacy** (R) — данные и приватность: блок «Что мы храним» кратко, строки: Скачать мои данные (JSON), Экспорт словаря (CSV) — реально; переключатели: «Мой английский» учитывает активность, аналитика использования; документы (Политика, Условия — некликабельные строки с ic-external оформи как button); danger «Удалить все мои данные» → Delete-account.
12. **Delete-account** (N) — подтверждение удаления: предупреждающая иконка-плашка (red), «Удалить аккаунт навсегда?», список что пропадёт (842 слова, стрик 12 дней, 37 текстов, подписка — отменится), поле «Введите УДАЛИТЬ для подтверждения» (пустое → кнопка disabled), dock: `b-red` disabled «Удалить навсегда» + `b-ghost` «Оставить аккаунт»; ссылка «Сначала скачать данные» → Data-privacy.
13. **Extension-connect** (R, реально) — расширение браузера: мини-иллюстрация «страница сайта → слово → карточка» (CSS-блоки), 3 шага подключения, блок «Новый токен — показан один раз» (mono, кнопка копировать, warn), «Активные токены» список (устройство, дата, «Отозвать» ≥44px), dock «Создать токен». Назад → Profile.
