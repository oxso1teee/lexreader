# Пачка D2 — ИИ-репетитор (тег: D2) — ВСЁ PLANNED
LLM-бэкенда в приложении НЕТ. Это проект будущей функции: каждый экран с `"planned":true`. Образец: src/AI-tutor-chat.html (не трогать). Визуальный язык ИИ: тёмно-зелёная «ink»-заливка (`.hero.ink`, `.sw.s-ink`, `.banner.ai`, `.badge.ink`) + жёлтая искра `ic-spark2`; репетитор — тот же маскот Lex. Никакого фиолетового. Вход — AI-hub (из Brain-home и Profile). Во всех экранах главное действие обычное зелёное `b-leaf`.

1. **AI-hub** (N) — входная страница репетитора: hero.ink с маскотом и «Репетитор Lex» + честная строка «В разработке — так он будет работать»; 5 возможностей карточками-строками с иконками (Чат-объяснения → AI-tutor-chat, Разбор ошибки → AI-explain, Проверка письма → AI-writing-check, Разговорная практика → AI-speaking, Произношение → AI-pronunciation, Упражнения под тебя → AI-generate); блок «Лимит: 20 сообщений в день на Free / безлимит в Plus» ; dock «Сообщить, когда появится» (b-leaf). Назад → Brain-home.
2. **AI-explain** (R) — разбор ошибки из занятия: «Ты написал» (.hl-r зачёркнуто) → «Правильно» (.hl-g), объяснение «Почему» простыми словами с выделением, 2 похожих примера, мини-проверка понимания (один вопрос с 2 вариантами `.opt`), dock «Понятно» + ghost «Ещё пример».
3. **AI-writing-check** (R) — отправка письма на проверку: чипы шаблона задания, карточка задания, поле с текстом (38 слов / минимум 50) и полосой прогресса, чек «что проверим: грамматика, лексика, стиль», dock «Проверить» (disabled до 50 слов), подпись про лимит.
4. **AI-writing-result** (R) — результат: кольцо уровня B1 + 3 оценки полосами (Грамматика, Лексика, Связность), текст с подсветкой 3 мест, список правок (тип-бейдж, было→стало, пояснение), блок «Что получилось хорошо», dock «Исправить и переслать» + ghost «Сохранить слова в карточки».
5. **AI-speaking** (R) — выбор сценария разговора: рекомендованный сценарий hero-карточкой (Собеседование, B1–B2, 8 мин), остальные списком (Заказ кофе, Спросить дорогу, Отель) с уровнем/временем — иконки вместо эмодзи; внизу активный диалог НЕ показывать — это экран выбора; dock «Начать разговор».
6. **AI-speaking-result** (N) — итог разговора: маскот joy, «8 минут разговора», 3 stat (реплик 14, новых слов 5, беглость «уверенно»), «Что улучшить» 2 пункта с примерами «ты сказал → лучше», «Полезные фразы» чипами → в карточки, dock «Готово», link2 «Повторить сценарий».
7. **AI-pronunciation** (R) — произношение слова: слово крупно + транскрипция по слогам (плитки слогов: хорошо/проблемный), кнопки «Образец» и запись (большой микрофон), результат 72% кольцом с подсказкой по проблемному слогу, история попыток (3 точки), dock «Ещё раз» + ghost «Следующее слово».
8. **AI-generate** (R) — генератор упражнений по слову/теме: источник (слово reluctant чипом + «изменить»), типы заданий `.check`-списком с количеством, сложность seg, предпросмотр одного сгенерированного задания карточкой, dock «Сгенерировать 8 заданий».
9. **AI-recommend** (R) — рекомендации репетитора: приветственная реплика маскота `.say` («Посмотрел 2 недели — вот с чего начать»), главная рекомендация hero.ink с причиной и CTA, 3 дополнительных строки (колода, текст, разговор) с причинами; отличие от Twin-recommendations — объяснения естественным языком; внизу ссылка «Как это устроено» → AI-hub.
