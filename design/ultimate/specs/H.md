# Пачка H — Адаптив: Desktop (1280×800) и Tablet (834×1112) (тег: H)
Это НЕ растянутые мобильные экраны. Реальное приложение имеет DesktopSidebar (те же 5 разделов) на широких экранах. Смотри мобильные эталоны: shots/v9a/light/Main.png, Library.png, Reader.png, Progress.png, Lesson-choice.png, Profile.png и shots/t1/light/Brain-home.png — контент и данные те же, композиция другая.

Desktop meta: `{"title":"…","w":1280,"h":800}`, корень `<div class="app desk">`: слева `<aside class="side">` (логотип: `<div class="logo"><i class="lex happy s40"></i>LexReader</div>`, 5 ссылок `<a class="on" href="D-Today.dc.html"><i class="ic ic-home"></i>Сегодня</a>` … Библиотека→D-Library, Практика→D-Practice, Прогресс→D-Progress, Профиль→D-Settings; внизу сайдбара (`.mta`) мини-карточка стрика 12 дней и XP), справа `<div class="main">` со своей шапкой и прокручиваемым содержимым (сделай `.main > .body` с `padding:24px 32px`, сетки через CSS grid в `<style>`). Контентная ширина ~1000px: используй 2–3 колонки (основная + правая панель 320px).
Tablet meta: `{"w":834,"h":1112}`, корень `<div class="app tablet">`: таббар остаётся снизу (шире, по центру max-width 520px) — либо узкий rail слева; контент в 2 колонки.
Размер шрифтов на desktop: h1 28px, основной 15–16px. Кнопки не на всю ширину (`.btn.fit`, min-width 200px).

1. **D-Today** — главная: приветствие + пилюли (уровень, стрик, XP) в шапке справа; основная колонка: hero «Занятие на сегодня» (широкий, с маскотом справа), ряд из 3 карточек (цель дня кольцо 30/50, 47 карточек на повтор, задания дня 2/3), «Продолжить чтение» широкой карточкой с обложкой; правая панель: неделя-стрик, рейтинг недели мини-топ-5 (моя строка выделена), общий стрик с Аней.
2. **D-Library** — библиотека: шапка с поиском на всю ширину и кнопкой «Добавить»; чипы-фильтры; «Читаю сейчас» 2 широкие карточки; сетка обложек 5 в ряд (обложка .cover.lg, название, уровень, прогресс); правая панель не нужна — вместо неё строка статов сверху (816 слов знаешь, 4 материала, лимит Free 3/3).
3. **D-Reader** — читалка: сайдбар свёрнут НЕ нужен — режим чтения без сайдбара: верхняя тонкая панель (назад, название, глава 3 из 5, прогресс, Aa, звук), по центру колонка текста 640px (.read 20px/1.7, буквица, подсвеченные слова как в мобильной), справа закреплённая панель слова 340px (reluctant: транскрипция, перевод, контекст, шкала знания, «В карточки») и под ней «Слова этой главы» списком. Корень `<div class="app desk">` без `.side`.
4. **D-Watch** — видео: слева плеер 16:9 (тёмный блок ~760px, контролы, текущий субтитр крупно под видео с кликабельными словами), справа панель-расшифровка: список реплик с тайм-кодами, текущая выделена, поиск по расшифровке, внизу панели «Сохранено 4 слова». С сайдбаром.
5. **D-Practice** — практика/Мозг: hero повторения (47 карточек) слева, справа 3 стата; ниже таблица колод (название, карточек, выучено %, на сегодня, кнопка «Учить») — настоящая таблица-список с заголовками колонок; правая панель: прогноз нагрузки на 7 дней (столбики), трудные слова (6) списком.
6. **D-Lesson** — упражнение на desktop: без сайдбара, верх: крестик + прогресс-бар по центру (max 720px) + стрик-комбо; по центру колонка 640px: тип задания, вопрос, предложение-контекст, 4 варианта в сетке 2×2 с клавишами 1–4, нижняя панель во всю ширину с «Проверить» справа и подсказкой «Enter — проверить, 1–4 — выбрать».
7. **D-Progress** — прогресс: seg-период в шапке; сетка: карточка стрика, 4 стата в ряд, большая теплокарта активности 12 недель, график XP по неделям (столбики), справа рейтинг недели и «Мой английский» мини-блок с 4 навыками.
8. **D-Settings** — профиль и настройки: двухпанельно: слева внутреннее меню разделов (Профиль, Обучение, Уведомления, Оформление, Подписка, Данные, Помощь) — активен «Оформление»/«Обучение», справа содержимое: профиль-шапка, цель дня, напоминания, тема оформления (3 плитки-превью: Светлая / Тёмная / Системная — выбрана), язык интерфейса.
9. **T-Today** — планшет, главная: шапка, двухколоночная сетка: слева hero + продолжить чтение, справа цель дня, повтор, неделя; таббар снизу по центру.
10. **T-Library** — планшет, библиотека: поиск + добавить, чипы, «Читаю сейчас» 2 колонки, сетка обложек 4 в ряд; таббар.
11. **T-Reader** — планшет, читалка: текст по центру 560px (.read 20px), снизу bottom-sheet слова на всю ширину, но содержимое в 2 колонки (слева слово/перевод/контекст, справа шкала знания и кнопки).
