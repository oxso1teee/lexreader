# Пачка A — Библиотека, контент, чтение (тег: A)
Родитель навигации: вкладка «Библиотека» (`Library`). Эталон стиля: Library.png, Reader.png.
R = переделать существующий, N = новый.

1. **Catalog** (R, PLANNED — жанров/каталога в БД нет) — подборки готовых материалов: поиск, чипы формата (Все/Тексты/Видео), чипы уровня CEFR, сетка тем 2×N с цветными обложками-плитками (Путешествия, Технологии, Культура, Новости, Классика, Бизнес — иконки вместо эмодзи), ниже «Популярное на B1» горизонтальная лента обложек. Таббар (Библиотека активна). Назад не нужен — это раздел библиотеки: `.hdr` c назад на Library.
2. **Genre** (R, PLANNED) — список материалов темы «Путешествия»: шапка-герой с названием темы и числом материалов, сортировка (seg: Популярное/Новое/Короткие), карточки-строки: обложка, название, уровень, длительность, число новых слов для тебя, прогресс если начато. Ссылки на Text-detail.
3. **Text-detail** (R) — страница материала «Treasure Island»: крупная обложка + название/автор, ряд фактов (уровень B1, 42 мин, 186 новых слов), «Насколько по силам» — полоса «знаешь 88% слов», описание, главы (список 5 глав с прогрессом/замком нет — все доступны), слова которые встретишь (чипы .word), dock: «Начать читать» + иконка «в коллекцию». Назад → Library.
4. **Search-results** (R) — поиск «light»: поле в фокусе с запросом и крестиком, seg Все/Тексты/Слова, секция «Тексты (2)» с подсветкой совпадения, «Слова (3)» из словаря со статусом, внизу подсказка «Не нашёл? Добавь свой материал» → Import-hub. Назад → Library.
5. **Collections** (R) — мои коллекции (реальная функция): сетка карточек-папок 2 колонки с мозаикой из 2–3 мини-обложек, названием и числом материалов; карточка-пунктир «Новая коллекция»; таббар не нужен, назад → Library.
6. **Collection-detail** (N, реальный маршрут /library/collections/[id]) — «Для отпуска»: шапка с названием, 6 материалов, общий прогресс; список материалов с обложкой и прогрессом; действия: переименовать/удалить в меню (iconbtn more), dock «Добавить материал».
7. **Favorites** (R, PARTIAL: избранное реально только для слов; для текстов — PLANNED → ставь planned:true) — seg «Тексты / Слова»; активна вкладка «Слова»: список избранных слов с переводом и сердцем; сверху баннер-инфо. Сделай полноценный экран, не три строки.
8. **Reading-history** (N, PARTIAL) — история чтения по дням: «Сегодня», «Вчера», «На этой неделе»: что читал, сколько минут, сколько слов сохранил; сверху сводка недели (96 мин, 3 материала, 24 слова). Назад → Library.
9. **Reading-goal** (R, PLANNED — отдельной цели чтения нет) — выбор недельной цели: крупный визуал (кольцо 2/3), варианты `.opt` с radio (1/3/5 текстов), переключатель напоминания, dock «Сохранить».
10. **Library-empty** (N) — библиотека нового пользователя: pagehead «Библиотека», маскот + «Здесь будут твои тексты», три крупных способа начать (взять готовый текст под уровень B1 / вставить свой текст / видео с YouTube), таббар.
11. **Import-hub** (R) — «Добавить материал»: 4 способа крупными карточками (Ссылка на статью, Видео с YouTube, Вставить текст, Фото страницы — PLANNED-бейдж `.badge.soon` «Скоро» на фото/OCR), блок «Лимит Free: 2 из 3 текстов» с полосой и ссылкой на Pricing-plans, блок про расширение браузера → Extension-connect.
12. **Import-text** (N) — форма вставки текста: поле «Название», большое поле текста с примером англ. текста и счётчиком слов, выбор уровня (авто/чипы), подсказка «выделим незнакомые слова», dock «Добавить в библиотеку» → Import-processing.
13. **Import-youtube** (N) — форма: поле URL (заполнено, `.ok`), карточка-превью найденного видео (обложка .cover.video, название «Life in London», 8:24, канал), статус субтитров («Есть английские субтитры» / или «Распознаем речь — займёт дольше»), dock «Импортировать видео». Покажи также состояние ошибки одной строкой-подсказкой ниже (hint).
14. **Import-processing** (R) — статус асинхронного импорта видео: крупный индикатор (кольцо % + маскот think), шаги с состояниями (готово / идёт / ждёт), «можно закрыть — пришлём уведомление», dock «В библиотеку» (ghost) . Назад → Library.
15. **Reader-phrase** (N) — читалка с выделенной ФРАЗОЙ: тот же текст что в Reader (смотри screens-v8/Reader.dc.html), выделена фраза «was reluctant to leave», bottom-sheet с переводом фразы, разбор по словам (чипы), кнопки «Сохранить фразу» / «Слушать». Используй `.read`, `.sheet` (без scrim — текст виден).
16. **Reader-settings** (N) — читалка + sheet «Вид текста»: размер шрифта (A− слайдер A+), гарнитура (seg: Literata / Onest), тема чтения (3 плитки: Светлая, Сепия, Тёмная), межстрочный интервал, переключатели «Подсвечивать новые слова», «Показывать перевод по тапу». Со scrim.
17. **Watch** (N, реальный маршрут /watch/[textId]) — видео «Life in London» с субтитрами: сверху плеер 16:9 (тёмный блок с кнопкой play, таймлайн, скорость 1×), под ним интерактивные субтитры — список реплик с тайм-кодами, текущая подсвечена, слова кликабельны (одно слово подсвечено как новое), нижняя панель: «Сохранено 4 слова» + кнопка «К карточкам». Шапка: назад → Library, название, Aa.
